# Astana Coffee - Midterm Project

## Topic
A website for a small coffee shop in Astana.

## Pages
- index.html - Home
- about.html - About
- menu.html - Menu (table)
- gallery.html - Gallery (CSS Grid)
- contact.html - Contact (form)

## Features
- Navigation bar on every page (Bootstrap navbar)
- Semantic HTML5: header, nav, main, section, footer
- Table (menu prices) and form (contact form)
- Flexbox (feature boxes), Grid (gallery)
- Positioning: fixed (navbar), relative + absolute (hero text)
- Media queries for tablet (768px) and mobile (576px)
- Bootstrap grid (row/col) and utility classes (mb-4, text-center, btn...)
